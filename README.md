# flatstow
CLI tool to link files written in python that i made since stows nestedness is too time consuming.

To install:
  ``` bash
curl -sSL https://raw.githubusercontent.com/nathanvella743/flatstow/main/main.py -o ~/.local/bin/flatstow && chmod +x ~/.local/bin/flatstow && echo -e "\n Flatstow installed to ~/.local/bin/\n  Warn: If 'flatstow' command is not found, ensure ~/.local/bin/ is in your PATH."
```

To use:
Simply run `flatstow`, it defaults to your CWD!
You can specify paths with flags. Run `flatstow --help` for information
